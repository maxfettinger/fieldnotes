These docs assume no experience with Hugo. Commands go into a **terminal** (Terminal on macOS, PowerShell or Windows
Terminal on Windows); everything else is text files you edit in any editor, such as
[Visual Studio Code](https://code.visualstudio.com/).

## Words you'll meet

| Word | What it means |
|---|---|
| Hugo | the program that turns your Markdown files into a website |
| theme | the templates, styles and scripts that decide how the site looks and works: here, Fieldnotes |
| site, or project | the folder with your content and your settings |
| `hugo.toml` | your site's settings file, in the folder's top level |
| Markdown | plain text with a few marks for headings, links and lists, in files ending in `.md` |
| front matter | the settings at the top of a Markdown file, between `---` lines |
| section | a folder in `content/`, like `posts/` or `trips/` |
| page bundle | a folder with an `index.md` and the page's files: its photos, its map |
| shortcode | a short tag in Markdown that inserts something bigger: `{{</* gallery */>}}` |
| preset | how Fieldnotes draws the site: fonts, background, cards, decoration |
| colour scheme | the colours, in a light and a dark version |

## How the docs are organised

[Getting started](getting-started/) takes you from nothing to a published site. [Writing](writing/) covers pages,
posts and Markdown; [Trips](trips/) the maps and galleries. [Look and feel](look/) explains presets, schemes, fonts
and colours, [Customizing](customizing/) how to change anything beyond them. The [reference](reference/) lists every
setting, and [Help](help/) has troubleshooting, working with an AI assistant, and the roadmap.
